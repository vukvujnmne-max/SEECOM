# SEECOM

**South East Europe Public Sector Communication Forum**

SEECOM is a regional forum connecting public-sector communication professionals across South East Europe.

This repository contains the source code for the SEECOM website.

## Website

https://seecom.info

## Technology

The website is built with Astro and the US Web Design System (USWDS), adapted for SEECOM.

## Local development

Requirements: Node.js and npm.

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build the website:

```bash
npm run build
```
